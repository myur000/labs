# Отчет по заданию 2.4

## Цель работы

Написать Python-скрипт, который читает адреса из `link.txt`, проверяет изменение содержимого страниц и сохраняет результат в `report.txt`.

Для сравнения между запусками используются хеши страниц, сохраненные в `hashes.json`. Сравнение выполняется с последней успешно полученной версией.

## 1. Используемые библиотеки

| Библиотека | Назначение |
| --- | --- |
| `requests` | Загрузка веб-страниц. |
| `hashlib` | Вычисление хеша SHA-256 для содержимого страницы. |
| `json` | Чтение и сохранение хешей между запусками. |
| `time` | Пауза между запросами. |
| `pathlib.Path` | Работа с файлами и путями. |

Все модули, кроме `requests`, входят в Python.

## 2. Необходимое окружение

Нужны Python 3, файл `link.txt`, доступ к проверяемым сайтам и право записывать файлы в папку задания.

Установка сторонней библиотеки:

```bash
python3 -m pip install requests
```

Используются три файла:

- `link.txt` — список адресов, по одному на строку.
- `hashes.json` — сохраненные хеши; создается автоматически.
- `report.txt` — результат текущего обхода.

## 3. Код скрипта

Код сохранить в файл `check_pages_simple.py` рядом с `link.txt`.

```python
import hashlib
import json
import time
from pathlib import Path

import requests

# Файлы со ссылками, состоянием и результатом.
LINKS_FILE = Path("link.txt")
HASHES_FILE = Path("hashes.json")
REPORT_FILE = Path("report.txt")
DELAY_SECONDS = 1

try:
    # Читаем адреса, пропускаем пустые строки и комментарии.
    lines = LINKS_FILE.read_text(encoding="utf-8-sig").splitlines()
    urls = [line.strip() for line in lines if line.strip() and not line.strip().startswith("#")]
    urls = list(dict.fromkeys(urls))

    # При первом запуске сохраненных хешей еще нет.
    hashes = json.loads(HASHES_FILE.read_text(encoding="utf-8")) if HASHES_FILE.exists() else {}
    if not isinstance(hashes, dict) or any(not isinstance(value, str) or len(value) != 64 for value in hashes.values()):
        raise ValueError("Неверный формат hashes.json.")
except (OSError, ValueError) as error:
    raise SystemExit(f"Ошибка чтения файлов: {error}")

report_lines = []
for index, url in enumerate(urls):
    try:
        # Загружаем страницу и вычисляем SHA-256 ее содержимого.
        with requests.get(url, timeout=10) as response:
            response.raise_for_status()
            if not 200 <= response.status_code < 300:
                raise ValueError("Неуспешный HTTP-ответ.")
            current_hash = hashlib.sha256(response.content).hexdigest()

        # Сравниваем новую версию с последней успешной.
        if url not in hashes:
            status, message = "NEW", "первый успешный обход"
        elif hashes[url] == current_hash:
            status, message = "OK", "без изменений"
        else:
            status, message = "CHANGED", "контент изменился"
        hashes[url] = current_hash
    except (requests.RequestException, ValueError):
        # При ошибке прежний хеш не меняется.
        status, message = "ERROR", "ошибка загрузки"

    report_lines.append(f"[{status}] {url} — {message}")
    if index < len(urls) - 1:
        time.sleep(DELAY_SECONDS)

try:
    # Записываем отчет и сохраняем обновленные хеши.
    REPORT_FILE.write_text("\n".join(report_lines) + ("\n" if report_lines else ""), encoding="utf-8")
    temporary = HASHES_FILE.with_suffix(".json.tmp")
    temporary.write_text(json.dumps(hashes, ensure_ascii=False, indent=2), encoding="utf-8")
    temporary.replace(HASHES_FILE)
except OSError as error:
    raise SystemExit(f"Ошибка сохранения файлов: {error}")

print("Отчет сохранен в report.txt, состояние — в hashes.json.")
```

## 4. Объяснение кода

### Шаг 1. Читается список адресов

`read_text()` читает файл, `splitlines()` разделяет его на строки, а `strip()` удаляет пробелы по краям. Пустые строки и комментарии с `#` пропускаются. `dict.fromkeys()` убирает повторяющиеся адреса, сохраняя их порядок.

### Шаг 2. Загружаются прошлые хеши

`HASHES_FILE.exists()` проверяет наличие `hashes.json`. Если файл есть, `json.loads()` превращает его содержимое в словарь. Если файла нет, создается пустой словарь `{}` — это первый запуск.

В словаре каждому URL соответствует хеш последней успешно загруженной страницы. Поврежденный JSON или неверный формат состояния останавливают программу с сообщением об ошибке.

### Шаг 3. Загружается страница

`requests.get(url, timeout=10)` получает страницу и ограничивает ожидание сетевых операций. `raise_for_status()` обнаруживает HTTP-ошибки. Конечный ответ должен иметь код 200–299.

### Шаг 4. Вычисляется хеш

`hashlib.sha256(response.content).hexdigest()` вычисляет SHA-256 по байтам тела ответа и возвращает строку из 64 шестнадцатеричных символов.

Хеш — компактное значение для сравнения содержимого. Он не является сохраненной копией HTML и не показывает, какие именно строки изменились.

### Шаг 5. Определяется статус

| Статус | Значение |
| --- | --- |
| `NEW` | Страница успешно получена впервые, старого хеша нет. |
| `OK` | Новый хеш совпал с сохраненным. |
| `CHANGED` | Новый хеш отличается от сохраненного. |
| `ERROR` | Страницу не удалось загрузить. |

После успешного запроса новый хеш становится эталоном. При ошибке старый хеш не меняется, а проверка остальных адресов продолжается.

### Шаг 6. Между запросами выполняется пауза

`time.sleep(DELAY_SECONDS)` делает паузу на одну секунду, чтобы уменьшить частоту запросов. `enumerate()` дает номер и адрес страницы, поэтому пауза выполняется только между проверками.

### Шаг 7. Сохраняются результаты

`report_lines` содержит строки отчета. `"\n".join(report_lines)` объединяет их с переносами строк, а `write_text()` записывает `report.txt`.

`json.dumps()` преобразует словарь хешей в JSON. Сначала записывается временный файл, затем `replace()` заменяет им прежний `hashes.json`. Это защищает старое состояние от частичной записи. Сам отчет при новом запуске перезаписывается.

## 5. Проверка работы

Для проверки использован локальный учебный сервер. В `link.txt` записаны:

```text
http://127.0.0.1:8000/page.html
http://127.0.0.1:8000/stable.html
http://127.0.0.1:8000/missing.html
```

В первом терминале из папки задания запускается приложенный сервер:

```bash
python3 demo_server.py
```

Во втором терминале выполняется проверка:

```bash
python3 check_pages_simple.py
```

Для демонстрации первого обхода нужна пустая история: удалить учебный `hashes.json`, если он уже есть. Это сбросит сохраненные хеши.

Результаты пяти последовательных запусков:

| Действие | Результат для page.html |
| --- | --- |
| Первый успешный обход | `NEW` |
| Повторный запуск без изменений | `OK` |
| Изменение текста страницы | `CHANGED` |
| Временное удаление страницы | `ERROR` |
| Восстановление последней успешной версии | `OK` |

Пример `report.txt` после изменения страницы:

```text
[CHANGED] http://127.0.0.1:8000/page.html — контент изменился
[OK] http://127.0.0.1:8000/stable.html — без изменений
[ERROR] http://127.0.0.1:8000/missing.html — ошибка загрузки
```

Адрес `missing.html` специально добавлен для проверки ошибки 404. Все пять обходов дали ожидаемые результаты. При ошибке загрузки прежние хеши сохранились.

Для настоящих сайтов нужно заменить адреса в `link.txt` полными HTTP/HTTPS-ссылками.

## Вывод

Скрипт загружает страницы, сравнивает их хеши с сохраненными и записывает результат в отчет. При повторном запуске история сохраняется.

Проверяется все полученное содержимое: динамическая дата или реклама тоже могут вызвать `CHANGED`. Скрипт обнаруживает факт изменения, но не показывает конкретные отличия.
