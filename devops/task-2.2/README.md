# Отчет по заданию 2.2

## Цель работы

Написать Python-скрипт, который читает адреса сайтов из `link.txt`, проверяет их доступность и записывает результат в `report.txt` в формате `адрес -> Ok` или `адрес -> Error`.

## 1. Используемая библиотека

В скрипте используется `requests`. Функция `requests.get()` отправляет запрос к сайту, а `response.status_code` содержит HTTP-код ответа.

Для файлов используется встроенная функция `open()`. Отдельная библиотека для нее не нужна.

## 2. Необходимое окружение

Нужны Python 3, библиотека `requests`, файл `link.txt` и право записывать `report.txt`. Для внешних сайтов требуется интернет.

Установка библиотеки:

```bash
python3 -m pip install requests
```

Адреса в `link.txt` записываются по одному на строку и должны начинаться с `http://` или `https://`.

## 3. Код скрипта

Код сохранить в файл `check_links_simple.py` рядом с `link.txt`.

```python
import requests

# Имена входного файла и отчета.
LINKS_FILE = "link.txt"
REPORT_FILE = "report.txt"

try:
    # Читаем адреса и пропускаем пустые строки.
    with open(LINKS_FILE, "r", encoding="utf-8-sig") as source:
        urls = [line.strip() for line in source if line.strip()]

    # Создаем отчет. При повторном запуске он перезаписывается.
    with open(REPORT_FILE, "w", encoding="utf-8") as report:
        for url in urls:
            try:
                # Загружаем страницу с ограничением ожидания.
                with requests.get(url, timeout=10) as response:
                    status = "Ok" if 200 <= response.status_code < 300 else "Error"
            except (requests.RequestException, ValueError):
                # Ошибка одного адреса не останавливает остальные проверки.
                status = "Error"

            # Записываем результат в формате из задания.
            report.write(f"{url} -> {status}\n")
except OSError as error:
    raise SystemExit(f"Ошибка работы с файлами: {error}")

print("Проверка завершена. Результат сохранен в report.txt.")
```

## 4. Объяснение кода

1. **Настройки.** `LINKS_FILE` задает имя входного файла, `REPORT_FILE` — имя отчета.

2. **Чтение адресов.** `open(..., "r")` открывает файл для чтения. `line.strip()` удаляет пробелы по краям и перенос строки. Условие `if line.strip()` пропускает пустые строки. В `urls` получается список адресов.

3. **Создание отчета.** Режим `"w"` создает `report.txt` или перезаписывает прежнее содержимое. Конструкция `with` автоматически закрывает файл после работы.

4. **Проверка сайтов.** Цикл `for url in urls` перебирает адреса. `requests.get(url, timeout=10)` запрашивает страницу и ограничивает ожидание сетевых операций. Обычные перенаправления обрабатываются автоматически.

5. **Выбор статуса.** Конечный код ответа от 200 до 299 считается успешным и дает `Ok`. Другие коды, например 404 или 500, дают `Error`. Здесь оценивается успешность запроса к указанному адресу, а не только наличие соединения с сервером.

6. **Обработка ошибок.** `try/except` перехватывает сетевые ошибки и некорректные адреса. Для них записывается `Error`, а проверка остальных адресов продолжается. Ошибки чтения или записи файлов обрабатываются отдельно.

7. **Запись результата.** `report.write()` сохраняет строку `адрес -> статус`. Символ `\n` переводит следующую запись на новую строку.

## 5. Проверка работы

Скрипт проверен на локальном учебном сервере. Адрес `127.0.0.1` означает этот же компьютер. Файл `demo_server.py` для проверки находится в папке задания.

Содержимое `link.txt`:

```text
http://127.0.0.1:8000/ok
http://127.0.0.1:8000/redirect
http://127.0.0.1:8000/missing
http://127.0.0.1:8000/server-error
неверный-адрес
ftp://example.com/
```

Для повторения проверки из папки задания в первом терминале запустить сервер:

```bash
python3 demo_server.py
```

Во втором терминале выполнить:

```bash
python3 check_links_simple.py
```

Полученный `report.txt`:

```text
http://127.0.0.1:8000/ok -> Ok
http://127.0.0.1:8000/redirect -> Ok
http://127.0.0.1:8000/missing -> Error
http://127.0.0.1:8000/server-error -> Error
неверный-адрес -> Error
ftp://example.com/ -> Error
```

Первый адрес вернул HTTP 200. Второй перенаправил на успешную страницу. Третий и четвертый вернули 404 и 500. Последние два не подходят для HTTP/HTTPS-проверки и также получили `Error`.

Все шесть результатов совпали с ожидаемыми. Для проверки настоящих сайтов достаточно заменить адреса в `link.txt`.

## Вывод

Скрипт читает список адресов, проверяет каждый из них и сохраняет отчет в требуемом формате. Ошибка одного сайта не останавливает проверку остальных.
