# Отчет по заданию 2.3

## Цель работы

Написать Python-скрипт, который загружает страницу сайта и извлекает текущие курсы валют. Такое извлечение данных из HTML называется парсингом.

Для работы выбрана [официальная страница Банка России](https://www.cbr.ru/currency_base/daily/). Скрипт выводит курсы доллара, евро, юаня и иены к рублю вместе с датой их действия.

## 1. Используемые библиотеки

| Библиотека | Назначение |
| --- | --- |
| `requests` | Загружает страницу сайта через HTTP-запрос. |
| `BeautifulSoup` из пакета `beautifulsoup4` | Разбирает HTML и позволяет найти таблицу, строки и ячейки. |

`html.parser` — встроенный HTML-парсер Python, который использует BeautifulSoup. Его отдельно устанавливать не нужно.

## 2. Необходимое окружение

Нужны Python 3, интернет и две библиотеки:

```bash
python3 -m pip install requests beautifulsoup4
```

Устанавливается пакет `beautifulsoup4`, а в коде он импортируется под именем `bs4`.

## 3. Код скрипта

Код сохранить в файл `currency_simple.py`.

```python
import requests
from bs4 import BeautifulSoup

# Страница с курсами и нужные валюты.
URL = "https://www.cbr.ru/currency_base/daily/"
CURRENCIES = ("USD", "EUR", "CNY", "JPY")

try:
    # Загружаем HTML и проверяем HTTP-ответ.
    response = requests.get(URL, timeout=10)
    response.raise_for_status()
    soup = BeautifulSoup(response.content, "html.parser")

    # Находим таблицу и дату действия курсов.
    table = soup.find("table", class_="data")
    date_input = soup.find("input", attrs={"name": "UniDbQuery.To"})
    if table is None or date_input is None or not date_input.get("value"):
        raise ValueError("Таблица или дата курсов не найдены.")

    # Проверяем, что порядок столбцов не изменился.
    headers = [" ".join(cell.get_text().split()) for cell in table.find_all("th")]
    if headers != ["Цифр. код", "Букв. код", "Единиц", "Валюта", "Курс"]:
        raise ValueError("Структура таблицы изменилась.")

    # Извлекаем данные из строк таблицы.
    rates = {}
    for row in table.find_all("tr"):
        cols = row.find_all("td")
        if len(cols) != 5:
            continue
        code = cols[1].get_text(strip=True)
        if code in CURRENCIES:
            units = cols[2].get_text(strip=True)
            currency = cols[3].get_text(strip=True)
            rate = cols[4].get_text(strip=True)
            rates[code] = f"{code} — {currency}: {rate} RUB за {units} ед."

    if len(rates) != len(CURRENCIES):
        raise ValueError("Не все выбранные валюты найдены.")

    # Выводим дату и найденные курсы.
    print("Дата действия курсов:", date_input["value"])
    for code in CURRENCIES:
        print(rates[code])
except (requests.RequestException, ValueError) as error:
    raise SystemExit(f"Ошибка: {error}")
```

## 4. Объяснение кода

### Шаг 1. Задаются адрес и валюты

`URL` содержит адрес страницы. В `CURRENCIES` перечислены буквенные коды нужных валют: USD, EUR, CNY и JPY.

### Шаг 2. Загружается страница

`requests.get(URL, timeout=10)` получает страницу и ограничивает ожидание сетевых операций. `response.raise_for_status()` обнаруживает HTTP-ошибки, например 404 или 500.

### Шаг 3. Разбирается HTML

`BeautifulSoup(response.content, "html.parser")` превращает полученный HTML в структуру, по которой можно искать элементы. `response.content` содержит байты ответа; BeautifulSoup определяет кодировку документа.

### Шаг 4. Находятся таблица и дата

`soup.find("table", class_="data")` находит таблицу с классом `data`. Именно такой класс используется на выбранном сайте вместо условного `rates-table` из примера задания.

`date_input` находит поле страницы с именем `UniDbQuery.To`. Его атрибут `value` содержит дату действия курсов.

Параметр называется `class_`, потому что слово `class` уже используется в языке Python.

### Шаг 5. Извлекаются значения из ячеек

`find_all("tr")` получает строки таблицы, а `find_all("td")` — ячейки каждой строки. Строка заголовков пропускается, поскольку в ней используются ячейки `th`.

У Банка России пять столбцов. Их индексы начинаются с нуля:

| Индекс | Содержимое |
| --- | --- |
| `cols[0]` | Цифровой код валюты. |
| `cols[1]` | Буквенный код, например USD. |
| `cols[2]` | Номинал — количество единиц валюты. |
| `cols[3]` | Название валюты. |
| `cols[4]` | Курс в рублях за указанный номинал. |

`get_text(strip=True)` извлекает текст ячейки и удаляет пробелы по краям. Условие `if code in CURRENCIES` оставляет только нужные валюты. Их данные сохраняются в словаре `rates`.

### Шаг 6. Выводится результат

`print()` выводит дату действия и курсы выбранных валют. Номинал сохраняется в выводе: например, курс JPY относится к 100 иенам, а не к одной.

### Шаг 7. Обрабатываются ошибки

`try/except` обрабатывает сетевые ошибки и отсутствие ожидаемых данных. Проверка заголовков обнаруживает изменение порядка столбцов, а проверка словаря — отсутствие выбранной валюты.

Если сайт изменит разметку, поиск элементов может потребоваться адаптировать.

## 5. Проверка работы

Запуск:

```bash
python3 currency_simple.py
```

При обращении к [странице Банка России](https://www.cbr.ru/currency_base/daily/) 22.10.2026 получен результат:

```text
Дата действия курсов: 22.10.2026
USD — Доллар США: 81,9739 RUB за 1 ед.
EUR — Евро: 91,9337 RUB за 1 ед.
CNY — Юань: 12,2806 RUB за 1 ед.
JPY — Иен: 51,7577 RUB за 100 ед.
```

Данные получены реальным запросом к сайту. При повторном запуске курсы и дата могут измениться. Это официальные курсы ЦБ, а не цены покупки или продажи валюты в коммерческом банке.

Скрипт загружает HTML-страницу, находит таблицу и извлекает нужные курсы. Пример из задания адаптирован к реальному сайту: изменены класс таблицы и номера ячеек, добавлены дата действия и номинал валюты.
