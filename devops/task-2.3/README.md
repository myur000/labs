# Задание 2.3. Парсинг текущих курсов валют

[← Задания DevOps](../README.md) · [Все учебные работы](../../README.md)

## Условие

Написать Python-скрипт, который загружает страницу сайта, находит на ней текущий курс валюты и выводит результат. Адаптировать пример с `requests` и `BeautifulSoup` к структуре реального сайта.

## Выбранный сайт

Источник — [официальная страница ежедневных курсов Банка России](https://www.cbr.ru/currency_base/daily/). Парсер работает с HTML-страницей: извлекает значения из таблицы, а не из JSON или XML API.

В работе выводятся USD, EUR, CNY и JPY. На странице курс указан в рублях за определенный номинал валюты. Например, значение для JPY относится к **100 иенам**, поэтому его нельзя считать ценой одной иены без деления на 100.

Скрипт показывает дату действия курсов, указанную на странице. Она может отличаться от даты запуска. Полученные данные — официальный курс ЦБ, а не цена покупки или продажи валюты в коммерческом банке.

## Установка и запуск

Нужен Python 3 с поддержкой HTTPS; для нового окружения рекомендуется Python 3.11 или новее. Также нужны доступ к сайту ЦБ и право записи в папку скрипта.

Команды для Linux/macOS из папки `devops/task-2.3`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 currency_rates.py
```

На Windows можно использовать `python` вместо `python3`, а в PowerShell активировать окружение командой `.venv\Scripts\Activate.ps1`.

Результат выводится в терминал и записывается в `rates.txt` рядом со скриптом. При успешном повторном запуске файл перезаписывается свежими данными с сайта. Приложенный к репозиторию файл — сохраненный результат проверки, он не обновляется автоматически.

## Используемые библиотеки

| Библиотека / модуль | Что делает |
| --- | --- |
| `requests` | `get(URL, timeout=10)` загружает страницу. `raise_for_status()` обнаруживает HTTP-ошибки 4xx/5xx. |
| `bs4.BeautifulSoup` | Разбирает HTML. `find()` находит таблицу и поле даты, `find_all()` — строки и ячейки, `get_text()` извлекает текст. |
| `decimal.Decimal` | Представляет курс десятичным числом и позволяет корректно разделить его на номинал. |
| `datetime` | Проверяет, что дата со страницы соответствует формату `дд.мм.гггг`. |
| `pathlib` | Задает путь к выходному файлу рядом со скриптом. |
| `sys` | Выводит ошибки и задает код завершения программы. |

Через pip устанавливаются только `requests` и `beautifulsoup4`; остальные модули входят в Python. Импортируется `bs4`, хотя имя пакета для установки — `beautifulsoup4`. Парсер `html.parser` встроен в Python и не требует отдельной установки.

## Адаптация примера под сайт

У Банка России таблица имеет класс `data`, а не `rates-table`:

```python
table = soup.find("table", class_="data")
```

В строке таблицы пять ячеек:

| Индекс Python | Столбец | Использование |
| ---: | --- | --- |
| `0` | Цифр. код | В данной работе не используется. |
| `1` | Букв. код | Код валюты: USD, EUR, CNY или JPY. |
| `2` | Единиц | Номинал, например 1 или 100. |
| `3` | Валюта | Название валюты. |
| `4` | Курс | Курс в рублях за указанный номинал. |

Поэтому извлечение названия и курса выглядит так:

```python
code = cells[1].get_text(strip=True)
currency = cells[3].get_text(" ", strip=True)
units = int("".join(cells[2].get_text().split()))
rate = Decimal("".join(cells[4].get_text().split()).replace(",", "."))
```

Индексация начинается с нуля. Пробельные разделители внутри чисел, включая неразрывные пробелы, удаляются; десятичная запятая заменяется точкой перед преобразованием в `Decimal`.

Дата берется из поля HTML с именем `UniDbQuery.To` и проверяется через `datetime.strptime()`. Заголовки таблицы сверяются с ожидаемыми, чтобы изменение порядка столбцов не привело к незаметному извлечению неверных данных.

### Неточности в комментариях задания

В комментарии к исходному двухстолбцовому примеру строка для названия валюты ошибочно повторяет присваивание `rate`. Для того примера правильно:

```python
currency = cols[0].get_text(strip=True)
rate = cols[1].get_text(strip=True)
```

Для выбранного сайта используются другие индексы: `cells[3]` и `cells[4]`.

Еще одна неточность: `raise_for_status()` вызывает исключение при HTTP-кодах 4xx/5xx, а не при любом статусе, отличном от 200. Например, успешный ответ 201 сам по себе исключения не вызывает.

## Алгоритм программы

1. Загружает HTML по постоянному адресу `URL` с тайм-аутом сетевых операций 10 секунд.
2. Проверяет HTTP-ответ и передает байты `response.content` в BeautifulSoup для определения кодировки.
3. Находит таблицу, сверяет заголовки и извлекает дату действия курсов.
4. Перебирает строки. Строка с заголовками `th` пропускается, поскольку в ней нет ячеек `td`.
5. Извлекает код, название валюты, номинал и курс, проверяет числовые значения.
6. Выбирает валюты из константы `CURRENCIES`, формирует текст. Для номинала, отличного от 1, дополнительно рассчитывает цену одной единицы: `курс / номинал`.
7. Сохраняет результат в UTF-8 и выводит его в терминал.

`parse_rates()` отвечает за разбор HTML, `format_report()` — за текст результата, `main()` — за загрузку и сохранение. Такое разделение позволяет проверять парсер без обращения к сайту.

### Обработка ошибок и ограничения

Если сеть недоступна, сервер вернул HTTP-ошибку, таблица исчезла, изменились заголовки, дата или числа некорректны, программа сообщает об ошибке и возвращает код `1`. Отсутствие выбранной валюты тоже считается ошибкой. Некорректный результат в `rates.txt` не записывается. При неудачном обновлении предыдущий файл может остаться на диске — его дату нужно проверять.

Парсер зависит от структуры HTML. Если сайт изменит разметку, селекторы потребуется обновить. JavaScript в программе не выполняется; для выбранной страницы это не требуется, поскольку таблица присутствует в полученном HTML.

## Подготовка к защите

| Возможный вопрос | Ответ |
| --- | --- |
| Что такое парсинг? | Извлечение нужных данных из документа по его структуре; здесь — из HTML-таблицы. |
| Почему нельзя взять селекторы из примера без изменений? | На реальном сайте другой класс таблицы и другое расположение столбцов. |
| Что означают `tr`, `td` и `th`? | Строка таблицы, ячейка данных и ячейка заголовка. |
| Почему параметр называется `class_`? | `class` — ключевое слово Python; библиотека использует имя с подчеркиванием. |
| Зачем нужен тайм-аут? | Чтобы ограничить ожидание сетевых операций. Он не гарантирует общее время всего запуска. |
| Зачем нужен `Decimal`? | Для десятичной арифметики без типичных погрешностей двоичного `float`; округление вывода задается явно. |
| Почему нужно учитывать номинал? | Значение может относиться к 100 единицам. Например, цену одной иены получают делением курса за 100 иен на 100. |
| Как добавить другую валюту? | Добавить ее буквенный код в `CURRENCIES`, например `"GBP"`. Код должен присутствовать в таблице. |
| Как узнать, что курс актуален? | Запросить страницу заново и посмотреть извлеченную дату действия. Сохраненный файл показывает результат прошлого запуска. |
| Как проверить программу без интернета? | Запустить модульные тесты: они передают искусственный HTML прямо в функцию разбора. |
| Что произойдет при изменении сайта? | Проверка таблицы или данных обнаружит проблему; затем нужно сверить новую разметку и обновить парсер. |
